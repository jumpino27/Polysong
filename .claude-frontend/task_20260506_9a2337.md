## This task

**Scope:** Polish the Polysong desktop app UI: app shell, library, panels, ingest/settings modals, player bar, visualizer preview, and fullscreen visualizer overlay.

**Design direction:** A local-first music workstation, not a marketing landing page. Make it feel like a focused audio lab: dense but calm, tactile controls, clear source provenance, strong Suno metadata visibility, serious motion for hiding/unhiding panels and fullscreen controls. **Stack:** React 19 + TypeScript + Vite + plain CSS modules via `App.css`/`index.css`, lucide-react already installed. No Tailwind is configured in this scaffold.
